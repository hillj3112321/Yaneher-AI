# Yaneher Community v11 — исходники

Это **обновление существующего проекта v10** для GitHub + Netlify + Supabase, а не самостоятельный HTML-макет. Интерфейс повторяет структуру предоставленного примера, без Plus, отдельного калькулятора и отдельной вкладки анализа видео.

**Начните с `README_УСТАНОВКА.md`.** Не заменяйте опубликованный сайт до настройки Supabase, создания резервной копии и теста на отдельном домене. Текущий опубликованный v10 **не изменён** этим архивом.

Папки: `site/` — браузерный интерфейс; `netlify/functions/` — Gemini и webhook; `db/` — настоящая PostgreSQL+RLS база; `video-worker/` — отдельно разворачиваемый FFmpeg/Gemini Files API; `legacy/` — резервная копия старого интерфейса; `docs/` — предоставленный графический концепт.
